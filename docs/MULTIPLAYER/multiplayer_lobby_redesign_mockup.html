📝 Multiplayer Lobby — 8 fixes
✅ Critical fixes:
  • 1. Mã phòng prominent — Block riêng đường nét gold border, code 32px font monospace, letter-spacing 6px. Là focal point của lobby (cốt lõi share). 3 actions inline (Copy / Link / QR) ngay dưới — không scattered.
  • 2. Bỏ "Chưa sẵn sàng" cho host — Host status = "Chủ phòng" với crown 👑, không cần ready toggle. Host control "Bắt đầu" trực tiếp.
  • 3. "Mời bạn bè" thành 1 slot riêng — Slot #2 luôn là "Mời" (gold dashed border, primary CTA visual). Click mở share modal hoặc copy code. Visible mọi lúc, không scattered.
✅ UX fixes:
  • 4. Empty slots khác nhau visual hierarchy — "Mời" (gold dashed) prominent, các slots khác (faded gray dashed) subtle. Không phải 6 slots giống nhau như cũ.
  • 5. Chat panel collapsible — Default HIDDEN khi <2 players (1 player thì không ai chat). FAB button góc phải để mở. Khi >= 2 players, chat panel mặc định mở (nếu desktop > 1100px width), nếu không thì FAB. Mobile luôn FAB (toggle to open as overlay/drawer).
  • 6. "Tao luc 00:21" bỏ — Meta info không quan trọng. Focus visual lên hero info + room code.
  • 7. Rules card collapse-friendly — Vẫn hiện nhưng compact hơn (chỉ 1 dòng + "Chi tiết →" link). Click "Chi tiết" mở modal full luật.
  • 8. Bỏ duplicate "Cần thêm 1 người" — Hiện chỉ 1 chỗ: trong players header inline. Bottom bar có status pulse + auto-start countdown hint.

2 states đã vẽ:

  • 1 player (alone) — Chat hidden, FAB only. Player slot #2 prominent "Mời bạn bè" gold. 6 slots faded. Bottom bar "Đang chờ thêm người chơi" với auto-start hint.
  • 4 players (full lobby) — Chat panel desktop expanded right (320px). System messages + chat history + 5 reaction buttons. 4 player slots filled (1 host crown, 2 ready green, 1 waiting purple). 1 invite slot + 3 empty. Status "Đủ người · Sẵn sàng" green. CTA "Bắt đầu chơi" enabled.

Player slot variants (6 states):

  • Host (gold border + crown 👑 + "Chủ phòng" tag)
  • Ready (green border + green avatar + "Sẵn sàng" tag)
  • Waiting (purple border + purple avatar + "Đang vào..." tag, animated)
  • Invite (gold dashed + person_add icon + "Mời thêm" — clickable)
  • Empty (gray dashed + hourglass + "Slot N" — non-interactive)
  • Disconnected (red border + "Mất kết nối" tag — for runtime, không hiện trong static mockup)

Chat panel logic:

  • Desktop, 1 player: chat HIDDEN, FAB visible
  • Desktop, >=2 players: chat EXPANDED panel right side (320px)
  • Mobile (mọi state): chat HIDDEN, FAB ở bottom-right. Tap → drawer slide từ phải
  • Notification badge trên FAB khi có new message chưa đọc (vd: "3" trong mockup mobile)
  • Empty state trong panel: icon chat + "Hãy chào hỏi để bắt đầu!" thay vì waste space

Differences cho 3 modes khác (cần adapt):

  • Battle Royale: hiện "❤️ Sai = Loại" trong rules card. Player slot có thêm "lives remaining" (3 hearts) khi in-game (không trong lobby).
  • Team vs Team: Players grid chia 2 columns: "Đội A" (red) | "Đội B" (blue). Drag-drop swap teams (host only). Auto-balance button. Mỗi team có team color border thay vì status color.
  • Sudden Death: Max 8 players nhưng layout khác — show queue order ("Position #1", "#2",...) vì chỉ 2 chơi 1 lúc. Nhãn "Đang đấu" cho 2 player active, "Chờ đợi" cho rest.

Câu hỏi cho Bui:

  • Auto-start logic — Mockup ghi "Auto-start 10s sau khi đủ ≥2 người". Có đúng không, hay host phải manual "Bắt đầu"? Code hiện thế nào?
  • Reactions trong lobby — Cho phép reactions (🙏 🔥 👏 💡 ✨) trong chat lobby trước khi game start? Hay chỉ during gameplay? Tôi thiết kế cả 2.
  • Public room visibility — Có public room listing trong /multiplayer page không? Hay chỉ join qua code? Spec §17.8 không nói rõ.
  • Kick player UX — Host có thể kick player không? Mockup chưa có. Pattern: hover player slot → ⋮ menu → "Kick".
