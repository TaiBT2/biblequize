Layout pattern
  • ·3-column: scoreboard (280px) · main (1fr) · chat/feed (320px)
  • ·Lobby: hero card + QR code + 2x4 player grid
  • ·Quiz: options grid 2×2 thay vì stack dọc — đỡ phải scroll
  • ·End host: 2-col (podium + actions panel)
  • ·End player: hero card hàng đầu + podium gọn
Khác biệt vs Mobile
  • ·Scoreboard luôn visible (sidebar) thay vì horizontal chip ở top
  • ·Chat persistent panel thay vì FAB drawer
  • ·Live feed riêng biệt với chat
  • ·BẮT ĐẦU! text-[12rem] thay vì text-6xl
  • ·Podium 3D hơn với heights 95-200px
  • ·Host actions panel riêng (không phải bottom-sticky)
💡
Use cases desktop
  • ·Hội thánh + projector: host chiếu desktop, players join từ phone
  • ·Mục sư/group leader: dùng laptop để monitor + analytics
  • ·User serious: chơi ranked nghiêm túc với màn hình lớn
  • ·Mobile remains primary nhưng desktop là force multiplier cho church group setting

Cần Bui quyết định

Có thêm "Host TV mode" riêng không? — pattern Kahoot: host máy chiếu chỉ show câu hỏi + đáp án + leaderboard cực lớn, KHÔNG có input. Players (kể cả host) thực sự chơi từ phone của mình. Phù hợp khi 1 host điều phối 20-30 người trong nhà thờ.

Nếu cần, đây sẽ là 1 file mockup riêng (`MOCKUP_DESKTOP_TV_HOST_MODE.html`) — không tích hợp vào file này vì layout & UX hoàn toàn khác (không có input form, font lớn gấp đôi, không scoreboard sidebar).
