Wire-up notes
Reveal trigger

Server gửi ROUND_END {correctAnswer, rankings[], explanation, scriptureRef} → FE switch state từ "optimistic" → "correct" hoặc "wrong" theo data.rankings.find(p => p.id === me).isCorrect.

Combo detection

FE track comboCount local. Hit 5 → show combo5 banner. Hit 10 → combo10 banner (gold + lớn hơn). Reset on wrong.

Wrong panel auto-dismiss

SPEC §4.5 nói 4s auto-dismiss. Trong multiplayer, server kiểm soát timing — auto-dismiss timer chỉ là UX, không skip server QUESTION_START tiếp theo.

Host detection

isHost = room.hostId === me.id. Render conditional CTA section. Cùng component QuizEndScreen với isHost prop.

⚠️
Edge cases cần cover
  • ·Timeout (không trả lời): coi như sai, vào state ④ với label "Hết giờ" thay vì "Bạn chọn"
  • ·Disconnect giữa câu: reconnect → server resync state, FE quyết định show optimistic hay reveal dựa trên server data
  • ·Battle Royale eliminated: state ④ thay nút "Tiếp tục" bằng banner "Bạn đã bị loại · xem các vòng còn lại"
  • ·Hòa điểm cuối trận: tie-break theo total responseMs (SPEC §5.4.1). Show 2 người ở vị trí 1 với badge "🤝 Hòa"
  • ·Solo (1 người): không bao giờ xảy ra trong multiplayer (min 2 người), nhưng nếu opponent leave → auto end với label "Đối thủ đã rời phòng"
