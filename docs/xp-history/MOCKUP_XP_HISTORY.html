notes Design notes

Source colors RANKED STAR DAILY
3 source types có 3 màu icon riêng để user phân biệt nhanh khi scroll. RANKED dùng gold (chính), STAR purple (giữa Tia Sáng-Vinh Quang), DAILY blue (calendar metaphor).
Entry pattern
Compact row: icon · title + meta · XP + chevron. Click anywhere → expand breakdown. STAR/DAILY không expand vì chỉ 1 số (+30/+50 flat) — không có chevron.
XP color = green #4ade80
Cộng điểm = positive, dùng green như success state. KHÔNG dùng gold để tránh confusion với section header / accent links.
Total trong breakdown = gold gradient
Tổng cộng được nhấn mạnh bằng gold gradient text giống QuizResults pattern hiện tại (đồng bộ visual).
Scope note (blue info banner)
Quan trọng để set expectation. User chơi Multiplayer thắng nhưng không thấy entry → confused. Banner clarify ngay từ đầu.
Start date banner (gold)
"Ship from now on" approach — KHÔNG backfill historical. Banner explain rõ user không cần lo "tại sao thiếu lịch sử cũ".
"Xem tất cả" link
Section trong Profile chỉ show ~5 entries gần nhất. Click → mở full page /profile/xp-history với pagination đầy đủ. (Optional — có thể defer, chỉ inline pagination.)
Drill-down "Xem chi tiết từng câu"
Chỉ trên RANKED entries (expanded). Link tới /review/:sessionId — extend Review page với pointsEarned per answer (Commit 7 trong prompt).
Tier multiplier hiện ×1.0?
User Tier 1 (Tân Tín Hữu) → multiplier ×1.0. Vẫn show row để user thấy "đây là cái tôi sẽ unlock khi lên tier" — motivation. Nếu confusing, có thể hide khi ×1.0.

notes Empty state notes

Trigger
Hiển thị khi GET /api/me/xp-history trả totalCount = 0. KHÔNG hiển thị scope note + start date banner trong empty state — giảm clutter.
2 CTAs
Primary (gold) → Ranked vì là main XP source. Secondary (outline) → Daily vì +50 quick win cho user mới. Cả 2 đều có icon match source type.
Icon = history_toggle_off
Material symbol có ý "lịch sử rỗng/chưa bắt đầu". Tone friendly, không alarming.
Tone
"Bắt đầu... để xem cách điểm được tính" — emphasize transparency value, không chỉ "chơi đi". Match purpose của feature (verify scoring).
