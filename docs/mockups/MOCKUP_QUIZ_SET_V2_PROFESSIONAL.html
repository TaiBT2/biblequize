⚠️ Edge cases
  • Multi-mode validation: Battle Royale cần ≥4 câu, Sudden Death ≥10 câu, Team vs Team cần chia chẵn được. Backend validate khi createRoom.
  • DRAFT visibility: Chỉ creator thấy. MEMBER list chỉ hiện PUBLISHED. Nếu DRAFT có scheduled quiz → block publish workflow.
  • Mastery sync: Solo practice tăng mastery. Live room đóng góp KHÔNG tăng mastery (Q-A logic riêng). Mastery KHÔNG vào group leaderboard.
  • Stats lag: playCount tăng async sau khi room ENDED (không phải IN_PROGRESS). Race condition handle bằng atomic update.
  • Migration legacy: Existing rows = PUBLISHED status, NULL metadata fields. Backfill description="" và difficulty derive từ existing questions.
