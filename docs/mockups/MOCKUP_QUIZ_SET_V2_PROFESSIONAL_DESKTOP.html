📐 Desktop layout differences vs Mobile
  • •
    3-pane list view: Sidebar nav (220px) + Folder pane (240px) + Grid 3-col cards. Mobile dùng single-column scroll.
  • •
    2-column detail: Hero + content (LEFT) + Stats sidebar (340px RIGHT) cho mastery + actions. Mobile stack vertical.
  • •
    Wide form layout: 2/3 form + 1/3 metadata sidebar (folder, status, auto-derived). Mobile single-column scroll.
  • •
    Mode picker = modal overlay: Centered max-w-4xl modal. Mobile = full-screen page.
  • •
    Question preview inline: Desktop hiện 3 câu đầu trong detail, click "Xem tất cả" expand. Mobile chỉ summary.
  • •
    Recent activity feed: Desktop có timeline activity inline. Mobile defer Sprint 6.
🎨 Design tokens consistent với mobile
  • ✓ Hex colors: #e8a832 (gold), #11131e (navy bg), #0a0c14 (deep bg), KHÔNG CSS vars
  • ✓ Be Vietnam Pro 800/900 cho headings tiếng Việt
  • ✓ Glass cards: rgba(50,52,64,0.55) + backdrop-blur(12px)
  • ✓ Mode badge colors: ⚡ gold / 📚 emerald / ⚔️ sky / 💀 orange / 🥊 purple
  • ✓ Same emoji icons: 📖 📜 ✝️ 🕊️ ⛪ 🎈 🌸 🎄 👑 ⚔️

  • ✓ Same mastery progress: emerald gradient bar, "Đã thuộc X/Y câu (Z%)"
