📝 Quiz Results redesign — 8 fixes
✅ Critical fixes (logic/data):
  • 1. Bỏ "Cố gắng thêm" framing — thay bằng tone phù hợp theo score:
    • ≥90%: "Xuất sắc!" 🌟 (gold-green gradient text)
    • 70-89%: "Tốt lắm!" 👏
    • 50-69%: "Khá hơn rồi!" 💪
    • 30-49%: "Đang học hỏi nhé!" 📚 (blue, encouraging)
    • 0-29%: "Sách này khó — chơi lại để vững hơn" 🎯
  • 2. Fix duplicate "Điểm cơ bản = Tổng cộng" — chỉ hiện score breakdown KHI có bonuses (speed bonus, combo, tier multiplier). Nếu không có bonus, gộp vào hero stats.
  • 3. Fix "Mạnh nhất = Cần cải thiện = Genesis" — replace bằng breakdown by difficulty (Dễ/TB/Khó với accuracy %) cho 1-book quiz. Bar chart ngắn gọn, useful insight.
✅ UX fixes:
  • 4. Streak card có data cụ thể — thay vì chỉ icon "Streak", hero insight nói rõ "+1 streak hôm nay 🔥". Streak status trong context, không phải standalone empty card.
  • 5. Visual hierarchy đúng — Hero block thống nhất: emoji + message + 3 stats (đúng/accuracy/time) trong 1 unit. Thay vì vòng tròn "3/10" lớn nhưng vô nghĩa, message emotional là trung tâm.
  • 6. Action button hierarchy đúng:
    • Primary (gold): "Chơi lại sách này" (low score) hoặc "Sách tiếp theo" (high score) — encourage progression
    • Secondary (outline): "Xem lại bài" — learn from mistakes
    • Tertiary (text link): "Về trang chủ" — escape route, không prominent
    Đảo so với hiện tại — "Trang chủ" KHÔNG phải primary CTA cho user vừa thua.
✅ Polish:
  • 7. Insight card mới — context comparison: "Bạn cao hơn 22% người chơi cùng sách". Frame of reference cho user biết 30% là tệ hay bình thường. Color shift theo state (purple low, green high).
  • 8. Compact spacing — Bỏ empty space dư. Mobile chỉ 1 viewport scroll thay vì 2-3 như hiện tại.

2 states đã vẽ:

  • Low score (3/10 = 30%) — hero message blue + "📚 Đang học hỏi nhé!" + insight encouraging + button "Chơi lại sách này" primary. KHÔNG có score breakdown vì practice mode không có bonus đặc biệt.
  • High score (9/10 = 90%) — hero message gradient gold-green + "🌟 Xuất sắc!" + score breakdown WITH bonuses (speed bonus, combo) + insight celebratory + button "Sách tiếp theo" primary (encourage progression).

Conditional rendering rules:

  • Score breakdown card: chỉ hiện khi có bonuses. Nếu chỉ base points, gộp vào hero stats.
  • Insight card: chỉ hiện nếu backend có data percentile. Skip nếu không.
  • Analysis section:
    • 1-book quiz → breakdown by difficulty (như hiện tại trong mockup)
    • Multi-book quiz → Mạnh nhất / Cần cải thiện (per book) — pattern cũ nhưng chỉ valid khi >= 2 books
  • Streak text trong insight: chỉ hiện khi user thực sự gain streak (Practice mode không tăng streak, chỉ Daily Challenge). Dynamic per mode.

Mode-specific variants (cần handle):

  • Practice: như mockup hiện tại — không XP, không tier multiplier, breakdown đơn giản
  • Daily Challenge: thêm "+50 XP" line trong score breakdown, "+1 streak" trong insight
  • Ranked: thêm tier multiplier line + leaderboard rank delta ("Bạn lên hạng từ #15 → #12")
  • Group activities (Live/Scheduled): hero stats include team/group rank, không phải percentile vs all users

Câu hỏi cho Bui:

  • Insight percentile data — backend có endpoint trả percentile not? Cần aggregate query "users đã chơi sách X với score Y, tôi xếp đâu?". Nếu không, skip insight card và replace bằng generic encouragement.
  • Hero emoji choice — tôi pick 📚 cho "đang học" và 🌟 cho "xuất sắc". Có muốn đổi (vd: ✨ thay 🌟, 🌱 thay 📚)?
  • "Sách tiếp theo" logic — high score case button này navigate đâu? Practice → next book in journey? Hay quay về book selection?
  • Confetti animation — high score state, có muốn confetti burst khi page load không? Tôi không animate trong static mockup, nhưng implementation có thể add với canvas-confetti library.
