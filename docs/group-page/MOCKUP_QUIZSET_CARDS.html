📝 Design notes

  • 3-section layout: header strip (status + book + menu) → body (title + difficulty + stats) → action footer. Loại bỏ vùng book icon vô nghĩa, gain ~40% useful space.
  • 1 primary + 2 icon buttons: "Chơi cùng nhau" là CTA chính (gold, scale on hover). "Đặt lịch" + "Solo" là icon buttons (40×40dp, đủ tap target). Tránh 3 button full-width tạo cramped UI.
  • Status-aware actions:
    • Published default → Co-play | Schedule | Solo
    • Already scheduled → Đăng ký tham gia | Solo (ẩn schedule, vì đã có)
    • User đã chơi → Co-play | Schedule | Refresh icon (Solo replay)
    • Draft → "Tiếp tục soạn" | Delete (ẩn play buttons hoàn toàn)
  • Difficulty pills 4/4/2 thay book icon — surface info quan trọng (mức độ khó) thay vì decoration.
  • Personal best banner chỉ hiện khi user đã chơi quiz set này — encourages replay + reinforces Q-A (personal mastery, không break group leaderboard).
  • Member-only buttons: Co-play / Schedule / Solo. Leader-only actions (sửa, lưu trữ, xóa) gom vào ⋯ menu để không clutter UI cho member.
  • Color discipline: tất cả hex hardcoded (gold #e8a832, glass rgba(50,52,64,0.4), blue #5b8df0 cho schedule context). KHÔNG dùng CSS variables.
