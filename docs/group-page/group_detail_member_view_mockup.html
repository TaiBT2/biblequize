📝 Member view — Permission diff với Leader
Permission matrix (per SPEC 9.1.3):
Action Leader Mod Member
Tạo quiz set ✅ ✅ ❌
Tạo phòng "Chơi cùng nhau" ✅ ✅ ❌
Đặt lịch Quiz tuần ✅ ✅ ❌
Tham gia phòng (đã mở) ✅ ✅ ✅
Chơi Quiz tuần ✅ ✅ ✅
Tự ôn solo ✅ ✅ ✅
Đăng announcement ✅ ✅ ❌
Mời thành viên ✅ ✅ ❌
Sửa group settings ✅ ❌ ❌
Xóa nhóm ✅ ❌ ❌

Khác biệt UI member vs leader:

  • Role badge sage (vs gold) — visual cue ngay đây là member view, ít power hơn.
  • Header actions chỉ 2 buttons: Thống kê (cá nhân + group view-only) + Rời nhóm (red, destructive). KHÔNG có Mời / Settings / Đăng announcement.
  • Hiển thị "Trưởng: TAI THANH" trong meta row — member biết ai là leader để liên hệ. Crown icon vàng nhỏ.
  • Hiển thị rank của user trong group "Hạng #12/47" — give context cho member họ đang ở đâu, motivation.
  • Quiz set card — single action "Tự ôn solo" thay vì 4 buttons. Card layout đơn giản hơn nhiều.
  • "Live call banner" prominent khi leader mở phòng — banner 1 lớn, animated pulse, gradient purple. Đây là main entry point cho member tham gia. Visual stronger hơn leader's view (vì leader đã trong context khi tạo phòng).
  • Empty state khác — leader thấy "Tạo bộ câu hỏi đầu tiên" CTA, member thấy explanation "Khi trưởng nhóm mở phòng, bạn sẽ thấy ở đây" (educate, không có action).

Use case mà mockup này cover:

  • Tab "Có activity": Member nhận push notification "Trưởng vừa mở phòng" → mở app → thấy live call banner prominent → 1 click "Tham gia phòng". Đây là happy path chính cho member.
  • Tab "Không có activity": Member mở app khi không có quiz đang chạy → empty state educate + access tự ôn solo.

API cần check (per role):

  • Existing endpoint GET /api/groups/{id} trả về userRole (leader/mod/member)
  • Frontend conditional render dựa trên role: {userRole === 'leader' || userRole === 'mod' && <CreateButtons />}
  • Backend authorize check ở từng endpoint POST/PATCH/DELETE — không tin client (member có thể hack request)

Câu hỏi cho Bui:

  • Mod role behavior — Mod có UI giống Leader không, hay restricted hơn? Per SPEC 9.1.3 mod có most permissions trừ Settings/Delete. Đề xuất: Mod UI = Leader UI - "Cài đặt nhóm" - "Xóa nhóm" - "Transfer leadership".
  • "Rời nhóm" button position — Hiện đặt trong header actions với màu red. Có nên move vào dropdown ⋮ (less prominent) không? Tôi đặt visible vì đây là action quan trọng cho member, không nên hide.
  • Member thấy quiz set của mod tạo — Có hiển thị "Tạo bởi: [Mod name]" trong meta không? Hiện chỉ show "X ngày trước". Tôi nghiêng add author để credit mod work.
  • Notification deep-link — Khi member nhận push "Phòng đang mở", click → mở thẳng vào lobby room hay vào Group Detail tab "Bộ câu hỏi"? Tôi nghiêng thẳng vào lobby để giảm friction.
