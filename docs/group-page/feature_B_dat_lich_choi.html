📝 Feature B — Đặt lịch chơi · Notes

Locked decisions:

  • Q8 3 lần/user, lấy điểm cao nhất · Q9 Max 3 active concurrent
  • Q10 Sau deadline: leaderboard frozen + auto-announcement + tab "Đã kết thúc"
  • Q11 KHÔNG cho chơi sau deadline (chỉ xem) · Q12 3 push noti (publish + 24h + ended)

3 màn hình chính:

  • Tạo lịch (form) — Tên + Quiz Set selector + Deadline (4 preset chips: 24h/7 ngày/14 ngày/Tùy chỉnh) + 3 toggles cài đặt. Nút "Đặt lịch & Thông báo" → tự động gửi noti cho cả group.
  • Đang diễn ra — Top: banner status (pulse green) + countdown card. Giữa: My status với 3 attempt cells (✓✓3) + best score + button "Chơi lần cuối". Dưới: live leaderboard cập nhật real-time, highlight user.
  • Đã kết thúc — Banner 🎊 + auto-posted to group announcement note + winner card prominent với crown 👑 + frozen leaderboard. Leader có CTA "Tạo quiz tuần mới".

Pattern thông minh:

  • 3 attempt cells visual — ✓✓3 ngay lập tức cho user biết còn bao nhiêu lần. Không cần đọc text "2/3".
  • Countdown smart format — "2 ngày 14h" ở trên 1 ngày, switch sang "5 giờ 23 phút" khi <24h, "12 phút" khi <1h. Không show giây.
  • Auto-announcement khi end — backend tự post vào group announcement với winner info. Member quay lại thấy noti rõ ràng, không phải tự dò leaderboard.
  • "Trưởng nhóm" tag trong leaderboard ngay sau tier — give context cho tại sao TAI THANH đứng #7 (vì là leader, có thể bận quản lý hơn là đi chơi).

API gap (cần thêm):

  • POST /api/groups/{id}/scheduled-quiz body: {quizSetId, name, description, deadline, settings}
  • GET /api/groups/{id}/scheduled-quiz — list active + upcoming + ended
  • GET /api/groups/{id}/scheduled-quiz/{quizId}/leaderboard — live data, frozen sau deadline
  • POST /api/groups/{id}/scheduled-quiz/{quizId}/play — bắt đầu lần thử mới
  • Cron job: chạy mỗi phút check deadline → freeze leaderboard + auto-create announcement + send push
  • Push noti scheduled-quiz: 3 events (created · 24h_remaining · ended)

Edge cases cần handle:

  • User join group SAU khi quiz đã publish — có cho chơi không? Đề xuất: YES, nhưng bị giới hạn bởi deadline còn lại.
  • User rời group khi đang chơi quiz — điểm có giữ trong leaderboard không? Đề xuất: YES, hiện tên + "(đã rời nhóm)" tag.
  • Leader xóa Quiz Set source — quiz đã publish tiếp tục dùng snapshot questions, không break.
  • Member chơi xong lần 1 với điểm cao, lần 2 thấp hơn — vẫn giữ điểm cao nhất.
