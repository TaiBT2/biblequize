📝 Group Detail Mobile · Notes

Khác biệt so với desktop:

  • Top bar pattern — Back button + breadcrumb "Nhóm / FMC Đà Nẵng" + Settings icon (gear). Settings là entry point cho Danger Zone (Xóa nhóm).
  • Group header compact — Avatar 52px (vs 72px desktop), name + role badge cùng row. Meta row inline thay vì grid. Actions thành 3 columns (2:1:1) với "Mời" primary, "Thống kê" và "Đăng" secondary.
  • Tabs horizontal scroll — 4 tabs vẫn hiển thị nhưng có thể scroll nếu thêm tab. Active "Bộ câu hỏi" (rename xong).
  • Activities horizontal scroll — Cards 280px width, scroll-snap. Hint card thứ 2 lú ra mép phải.
  • Quiz set card 3-row layout:
    • Row 1: Icon + Name + meta wrap + ⋮ menu
    • Row 2: 2 primary actions side-by-side (Chơi cùng nhau · Đặt lịch)
    • Row 3: "Tự ôn solo" full-width ghost button (less prominent, secondary action)
✅ Tất cả 6 fixes đã apply:
  • 1. Test data "tett" → realistic names · Empty state có CTA prominent
  • 2. Buttons hierarchy: 2 primary (purple/blue) row trên + 1 secondary "Tự ôn" row dưới + ⋮ menu
  • 3. Xóa Nhóm → Settings page (gear icon top-right)
  • 4. Header cleaned: bỏ duplicate name, invite code (vào button "Mời"), thay bằng activity status
  • 5. Section "Đang diễn ra" với horizontal scroll cards
  • 6. Tab "Quiz nhóm" → "Bộ câu hỏi"

Mobile-specific tweaks:

  • Tự ôn xuống dưới — Trên desktop 4 buttons cùng row (Tự ôn ghost · Chơi cùng nhau · Đặt lịch · ⋮), trên mobile thiếu width nên tách: 2 primary lên grid 2-col + Tự ôn secondary full-width row riêng (less prominent visual). Ghost button + label "Tự ôn solo" để clarify đây không phải group action.
  • Action buttons trong header rút gọn — "Mời thành viên" → "Mời", "Cài đặt" → icon only (gear). Tiết kiệm width.
  • Tag "Đang dùng cho Quiz tuần" rút gọn thành "Đang dùng" — fit width 358px.
  • Activities horizontal scroll — pattern quen thuộc trên mobile (giống groups public discovery).

Touch targets: Tất cả interactive elements ≥ 44×44px. Quiz set card có 3 distinct tap zones (card body navigate detail, 2 primary buttons, Tự ôn button, menu icon). ⋮ menu icon chỉ 32px nhưng có padding xung quanh đảm bảo hit target ≥ 40px.

Total page length:

  • State có data: ~1,400px (Header + Tabs + 2 sections + 3 quiz cards + History)
  • State empty: ~620px (Header + Tabs + Empty state)
